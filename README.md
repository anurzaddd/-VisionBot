## 🚀 What is VisionBot?

**VisionBot** is a next-generation web automation bot that **sees** web pages like a human. Instead of relying on brittle HTML selectors, it uses:

- 👁️ **Vision-Language Models** (GPT-4V, LLaVA) to analyze screenshots
- 🖱️ **Human-like interactions** with mouse movements and clicks
- 🧠 **AI-powered decision making** to navigate and interact with websites

| Feature | Description |
